# gh-448: Claude harness accepts a built-in skill that registers late

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/448

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN an init event lists a skill that the inventory does not know, and a new command listing marks it built-in, THE SYSTEM SHALL pass the live preflight with one live call and claim no budget call for the listing. |  |
| AC-2 | test | WHEN an init event lists an unknown skill that a new command listing does not mark built-in, THE SYSTEM SHALL stop with `preflight-leak` or `isolation-failed`. |  |
| AC-3 | test | WHEN a task call lists a late built-in skill, THE SYSTEM SHALL run it, and WHEN the init event lists only the expected skill, THE SYSTEM SHALL NOT list the commands again. |  |

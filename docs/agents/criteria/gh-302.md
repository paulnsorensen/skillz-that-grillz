# gh-302: prose+cli proposals leak runner context into candidate code comments

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/302

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN `prose+cli` builds a reflection prompt THE SYSTEM SHALL permit a change to a script's command-line interface and require that every caller and skill text reference matches it. |  |
| AC-2 | test | WHEN `prose+cli` builds a reflection prompt THE SYSTEM SHALL tell the proposer not to put facts about the prompt, the search, or the host into a component. |  |
| AC-3 | test | WHEN `prose+cli` offers a wedge source or `@new-cli` THE SYSTEM SHALL send the fromargs rule. |  |
| AC-4 | test | WHEN `prose+cli` offers no wedge source and no `@new-cli` THE SYSTEM SHALL send no wedge or fromargs text. |  |
| AC-5 | test | WHEN `--edit` is omitted and the skill has a helper script THE SYSTEM SHALL plan `prose+cli` components and record `edit` as `prose+cli`. |  |
| AC-6 | test | WHEN `--edit` is omitted and the skill has no editable helper script, no own wedge source, and no usable `@new-cli` THE SYSTEM SHALL plan `prose` without a stop, record `edit` as `prose`, and write one note on stderr. |  |
| AC-7 | test | WHEN `--edit prose+cli` is explicit and the skill has no editable helper script THE SYSTEM SHALL stop with `helper-missing`, also when `settle` drops `@new-cli`. |  |
| AC-8 | test | WHEN a run resumes without `--edit` THE SYSTEM SHALL keep the `edit` mode of the first run, including a fallback to `prose`. |  |
| AC-9 | test | WHEN `--edit` is omitted, `@new-cli` is offered, and `settle` drops it THE SYSTEM SHALL plan `prose` without a stop, record no wedge or `@new-cli` component, seed the same candidate as `--edit prose`, and write one note on stderr. |  |
| AC-10 | test | WHEN a run offers no `@wedge/` source and no `@new-cli`, and a proposal adds `wedge.toml`, `fromargs`, or `@new-cli` as a whole token, THE SYSTEM SHALL reject the proposal with the leakage rule `runner-term` before any task or judge call. |  |
| AC-11 | test | WHEN the run offers a `@wedge/` source or `@new-cli`, the seed already holds the term, or the term is part of a longer token, THE SYSTEM SHALL not fire `runner-term`. |  |

# gh-411: fromargs bounds its traceback files in a per-user directory

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/411

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN fromargs handles more than 20 unexpected exceptions THE SYSTEM SHALL keep only the newest 20 traceback files in one per-user directory, and the file that the last message names SHALL exist |  |
| AC-2 | test | WHEN fromargs writes a traceback file THE SYSTEM SHALL create its directory with no group or world permission bits |  |
| AC-3 | process | WHEN `just build` runs THE SYSTEM SHALL pass every gate | `just build` exits 0 |
| AC-4 | test | WHEN the per-user traceback directory is a symlink or has group or other permission bits THE SYSTEM SHALL refuse the symlink and make the directory private |  |

# gh-319: one model call cannot use the whole search window, and calls reconcile with outcomes

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/319

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | THE SYSTEM SHALL give each model call (Codex and command harness) a per-call timeout of 4 times the run plan's per-call time estimate, capped by the remaining search time. |  |
| AC-2 | test | WHEN a task or judge call exceeds its per-call timeout, THE SYSTEM SHALL record an `evaluation-failed` outcome with reason `timeout`; WHEN a reflection call does, THE SYSTEM SHALL end that proposal with no candidate. |  |
| AC-3 | test | THE SYSTEM SHALL record every claimed call, including failed reflection and judge calls, so that `calls` in `run.json` equals the sum of the recorded calls by role. |  |
| AC-4 | test | WHEN the search deadline ends the search with more than half of the search call budget unspent, THE SYSTEM SHALL report the search reason `time-exhausted` and the seconds spent by role (task, reflection, judge, failed). |  |

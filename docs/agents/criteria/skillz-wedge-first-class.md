| --- | --- | --- | --- |
| AC-1 | process | WHEN a skill holds a foreign `.pyz`, another non-UTF-8 file, or a text file over the per-file text limit THE SYSTEM SHALL carry it as frozen bytes in the workspace and identity, never editable and outside `PACKAGE_LIMIT`, and SHALL run `--edit prose` without `undecodable-file` | pre-gate: PR #196 review |
| AC-2 | process | WHEN a frozen file exceeds 16 MiB, or the candidate's frozen bytes exceed 64 MiB, THE SYSTEM SHALL stop with `frozen-file-too-large` naming the file; WHEN frozen bytes change THE SYSTEM SHALL change the identity without changing the text total | pre-gate: PR #196 review |
| AC-3 | test | WHEN `wedge.toml` declares two `[[target]]` tables THE SYSTEM SHALL build `scripts/<name>.pyz` for each, and `wedge bundle --check` SHALL verify each; WHEN it uses the single-target form THE SYSTEM SHALL build byte-identically to before |  |
| AC-4 | test | WHEN a build uses a populated site layer THE SYSTEM SHALL produce a byte-identical `.pyz` to a fresh build, SHALL make no network call, and SHALL leave the layer unchanged |  |
| AC-5 | process | WHEN `--edit prose+cli` targets a skill with own targets THE SYSTEM SHALL make editable the helper target and then SKILL.md-referenced targets while the text total fits, SHALL keep every other own target as frozen built bytes, and SHALL never make a `.pyz`, `wedge.toml`, or `uv.lock` editable | pre-gate: PR #196 review |
| AC-6 | test | WHEN a candidate changes an own target's source THE SYSTEM SHALL rebuild that `.pyz` on the host before `check_candidate`, and a task SHALL run it as `python3 -I scripts/<name>.pyz` inside the real sandbox |  |
| AC-7 | process | WHEN a candidate's own-target build fails THE SYSTEM SHALL reject the candidate with reason `build-failed` | pre-gate: PR #196 review |
| AC-8 | process | WHEN candidate source contains import-time code that writes a canary file THE SYSTEM SHALL build the target and the canary SHALL not exist on the host afterwards | pre-gate: PR #196 review |
| AC-9 | process | WHEN a winner changes `@wedge/` files THE SYSTEM SHALL write `wedge-sources.patch` with repo-relative paths inside the repository root that apply from the repository root, and the skill patch SHALL apply from the skill dir including added skill files (produced only by C4's `@new-cli`; fabricated winners stand in until then); WHEN an `@wedge/` path resolves outside the repository root or fails the `relative()` rules THE SYSTEM SHALL refuse the export with a named error | pre-gate: PR #196 review |
| AC-10 | process | WHEN the inspector runs on the fixtures THE SYSTEM SHALL return exit 0 with `schema_version` 4 JSON on stdout, or exit 3 with empty stdout and a JSON error on stderr, and `fixture_result` SHALL compare both streams while the sandbox-setup stderr check stays separate | pre-gate: PR #197 review |
| AC-11 | process | WHEN the legacy contract runs under `prose+cli` THE SYSTEM SHALL resolve `scripts/inspect-skill.pyz` to its target without `helper-file-missing`, SHALL edit the `skillz_inspect` source, and SHALL rebuild `inspect-skill.pyz` per candidate | pre-gate: PR #197 review |
| AC-12 | process | WHEN `prose+cli` edits wedged Python source THE SYSTEM SHALL send a reflection prompt that names fromargs and cites its contract; WHEN a helper is shell or another non-Python language THE SYSTEM SHALL keep it valid | pre-gate: PR #198 review |
| AC-13 | process | WHEN the skill owns a fromargs-capable `wedge.toml` and a proposal sets `@new-cli` THE SYSTEM SHALL add one target within the existing lock and with no dependency group (base dependencies only), build it, and score it; WHEN the skill has no such `wedge.toml` THE SYSTEM SHALL not offer `@new-cli` | pre-gate: PR #198 review |
| AC-14 | process | WHEN a proposal's `@new-cli` has an extra key, malformed TOML (including a non-string module or deep nesting), a bad name (including a non-string name or a Python keyword), a target-name or package collision (including a site-layer module), an oversized module or value, a module that does not parse or has no top-level `main`, an undeclared import, or a second target THE SYSTEM SHALL reject the candidate with a named reason, and SHALL not execute the module | pre-gate: PR #198 review |

# gh-499: reject proposals that copy harness text into the target (#320 Part 3)

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/499

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a proposal adds `output/plan.json` to an editable file AND a train or validation request holds it AND no seed file holds it THE SYSTEM SHALL reject the proposal with leak rule `harness-token` |  |
| AC-2 | test | WHEN the contract declares `harness_phrases: ["do not run git or gh"]` AND a proposal adds "Do not run git or gh." THE SYSTEM SHALL reject the proposal with leak rule `harness-token` |  |
| AC-3 | test | WHEN seed file `reference.md` holds `output/report.md` AND a request holds it AND a proposal adds it to `SKILL.md` THE SYSTEM SHALL accept the proposal; WHEN no seed file holds it THE SYSTEM SHALL reject it |  |
| AC-4 | test | WHEN the run builds its denylist THE SYSTEM SHALL expose the full harness-token list, seed-held tokens included, through the `search` facade, AND mask SHALL replace each occurrence with `[harness]` |  |
| AC-5 | test | WHEN the `harness-token` rule rejects a proposal THE SYSTEM SHALL count it under `search.leakage_rejections["harness-token"]` in `run.json`, AND a run SHALL record a `leakage_digest` different from the previous release |  |
| AC-6 | test | WHEN a contract holds an empty `harness_phrases` list or omits it THE SYSTEM SHALL compute the same `contract_hash` as before; WHEN it holds a one-word phrase contract loading SHALL fail with a coded error |  |
| AC-7 | test | WHEN a request holds backticked `output/pr-<n>.md`, sentence-final `output/halt.md.`, and `capture/log.txt` THE SYSTEM SHALL reject proposals that add `output/pr-7.md`, `output/halt.md`, or `capture/log.txt`, AND SHALL accept a proposal that adds only the word "output" |  |
| AC-8 | test | WHEN only a holdout request holds `output/secret.json` THE SYSTEM SHALL accept a proposal that adds it; WHEN a journey `brief` holds `output/plan.json` THE SYSTEM SHALL reject a proposal that adds it |  |

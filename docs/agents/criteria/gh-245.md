# gh-245: selectable validation policy

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/245

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a run omits `--val-policy`, THE SYSTEM SHALL use full validation and preserve its metric counts. |  |
| AC-2 | test | WHEN a run selects `subset`, THE SYSTEM SHALL score a fixed seeded half during search, complete qualifying finalists, and promote only fully validated candidates. |  |
| AC-3 | test | WHEN a run resumes, THE SYSTEM SHALL retain an omitted policy and reject a changed explicit policy with `run-config-differs`. |  |
| AC-4 | test | WHEN the controlled search runs for five seeds, THE SYSTEM SHALL record metric-call counts and winner identities for both policies. |  |
| AC-5 | process | WHEN the policy evidence is reviewed, THE SYSTEM SHALL record savings, winner agreement, and the default or C8 decision without changing this default. | `skills/skillz/references/experiments.md` validation policy study; `docs/agents/decisions/skillz-autoimprove.md` ADR-031 |
| AC-6 | test | WHEN a run selects `subset`, THE SYSTEM SHALL keep progress planning and the estimate based on full validation. |  |

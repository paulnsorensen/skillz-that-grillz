# gh-241: record per-proposal attempts and show broke/fixed history to the proposer (W4.4)

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/241

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a proposal is evaluated THE SYSTEM SHALL record one attempt with the train case ids it fixed and broke against its parent. A duplicate outcome for one case SHALL resolve to the newest outcome that did not fail. |  |
| AC-2 | test | WHEN the next reflection prompt is built THE SYSTEM SHALL list the newest 8 attempts, newest first, with hypothesis, fixed ids, and broke ids, plus the protect set, within 4000 characters. |  |
| AC-3 | test | WHEN a run resumes THE SYSTEM SHALL keep the earlier attempts, continue the index, and keep the `text_dropped` count, all rebuilt from the recorded outcomes. |  |
| AC-4 | test | WHEN a holdout case holds a distinctive string THE SYSTEM SHALL keep that string out of every attempt and every prompt. |  |
| AC-5 | test | WHEN a reflection answer has no `@hypothesis` THE SYSTEM SHALL accept it and record a null hypothesis. |  |
| AC-6 | test | WHEN a hypothesis copies a train request span THE SYSTEM SHALL store null, record `hypothesis_dropped` as `request-span`, add 1 to `text_dropped["request-span"]`, and still admit the proposal. |  |
| AC-7 | test | WHEN the request schema is built THE SYSTEM SHALL list `@hypothesis` in `required` with type `["string", "null"]` and no `maxLength`. The `accept` function SHALL return null for a hypothesis over 200 characters. |  |
| AC-8 | test | WHEN a clean proposal follows a prompt that shows the history THE SYSTEM SHALL leave `leakage_rejections` unchanged. |  |
| AC-9 | test | WHEN the shape check, `_admit`, or the proposal build rejects a proposal THE SYSTEM SHALL record an attempt with a null candidate and the exact reason. Each such attempt SHALL survive a resume. A legacy outcome SHALL give empty fixed and broke lists. |  |
| AC-10 | test | WHEN a search ends THE SYSTEM SHALL hold `reason`, `leakage_rejections`, `attempts`, and `text_dropped` together in `record["search"]`. |  |

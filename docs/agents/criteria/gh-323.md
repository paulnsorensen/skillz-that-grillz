| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN the runner starts Claude Code THE SYSTEM SHALL set `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` to `0` in the child environment, whatever the host sets. |  |
| AC-2 | process | WHEN the live preflight runs on a host that blocks the nested user namespace THE SYSTEM SHALL pass with a runner-owned host pathname Unix socket unreachable, and SHALL keep the socket probe fail-closed. | Live A/B on Claude Code 2.1.301, Linux 7.0.0-38, same floor and harness environment. With `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1`: the pathname socket connected and the listener got the token. With the value `0`: the connect failed with ENOENT and the listener got nothing. Before the fix, the live preflight stopped with `network-isolation-failed`. See the `Amendment 2026-10-16` in `docs/agents/decisions/skillz-autoimprove.md`. |

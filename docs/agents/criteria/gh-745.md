# gh-745: report seed capacity in validation

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/745

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN `validate` or `plan` has a seed THE SYSTEM SHALL report its exact serialized bytes, limit, and remaining bytes |  |
| AC-2 | test | WHEN fewer than 10 percent of seed bytes remain THE SYSTEM SHALL warn, but not warn at the threshold |  |
| AC-3 | test | WHEN a seed exceeds its limit THE SYSTEM SHALL report bytes, limit, overage, and at most five largest unique fixture paths and sizes without fixture content |  |
| AC-4 | test | WHEN the distinct-fixture bound stops early THE SYSTEM SHALL report a lower bound and not claim an exact serialized size |  |

# gh-589: a seed fixture can be a png, jpg, webp, or gif image

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/589 (spec autoimprove-seed-signals C5)

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a fixture under `evals/files/` starts with png, jpg, webp, or gif magic bytes THE SYSTEM SHALL seed it as `{"base64", "type"}`, count its encoded size once toward the seed limit, stage the exact bytes in the task workspace and the grading workspace, and give the judge a placeholder instead of the bytes. A file that decodes as UTF-8 stays text, even when it starts with image magic |  |
| AC-2 | test | WHEN a fixture is not UTF-8 text and not an allowlisted image THE SYSTEM SHALL stop with `evals-unreadable`, and a text-only seed and its case hash SHALL stay byte-identical |  |

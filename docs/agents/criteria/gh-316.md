# gh-316: a run that is mostly provider faults stops with a code and scores no fault as zero

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/316

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a search evaluation ends `evaluation-failed`, THE SYSTEM SHALL exclude it from validation means, stall observations, and reflection feedback, as the holdout gate does. |  |
| AC-2 | test | WHEN at least 4 search evaluations have finished and more than half failed, or 5 consecutive search evaluations fail with a provider fault, THE SYSTEM SHALL stop the search with the coded error `search-faulted`. |  |
| AC-3 | test | THE SYSTEM SHALL report `search.scored`, `search.failed`, and failed counts by reason in the run summary and the export report. |  |
| AC-4 | test | WHEN a run ends with no scored holdout comparison because of provider faults, THE SYSTEM SHALL exit nonzero. |  |
| AC-5 | test | WHEN every validation outcome of a candidate is unscored, THE SYSTEM SHALL NOT select that candidate over the seed. |  |

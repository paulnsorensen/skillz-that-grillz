# gh-406: wedge strips install metadata only inside *.dist-info

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/406

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN wedge builds a pyz THE SYSTEM SHALL strip `RECORD`, `INSTALLER`, `REQUESTED` and `direct_url.json` only inside an installed `*.dist-info` and keep a file of one of those names that is outside `*.dist-info` |  |
| AC-2 | test | WHEN a first-party source tree holds a nested `*.dist-info` directory THE SYSTEM SHALL keep its files in the built pyz |  |

# gh-658: warn when the train split has almost no headroom

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/658 (spec `autoimprove-seed-signals`, C1)

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN fewer than 2 train cases have headroom (a seed score below 1 on some repeat: a scored case that is not `saturated` and not a pass-to-pass floor case; a `suspect-zero` case has headroom) and the run is not `min_token_saving` THE SYSTEM SHALL print a warning before the search, store it in `headroom.warnings`, and continue |  |
| AC-2 | test | WHEN the headroom pass finishes THE SYSTEM SHALL record the saturated case counts per family and per split, and `export` SHALL show them with `headroom.warnings` |  |

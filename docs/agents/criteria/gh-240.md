# gh-240: detect search stalls and stop GEPA through stop_callbacks (W4.3)

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/240

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN 3, 5, and 8 consecutive known observations are `none` THE SYSTEM SHALL return `warn`, `shift`, and `stop`. |  |
| AC-2 | test | WHEN a `gain` arrives THE SYSTEM SHALL reset the streak to 0. |  |
| AC-3 | test | WHEN `unknown` observations arrive THE SYSTEM SHALL leave the streak unchanged. |  |
| AC-4 | test | WHEN a controlled-transport run stalls for 8 proposals THE SYSTEM SHALL stop the search, record `converged-stalled`, and still run the gate. |  |
| AC-5 | test | WHEN the run resumes THE SYSTEM SHALL rebuild the same signal from the record. |  |
| AC-6 | test | WHEN `experiments.md` is read THE SYSTEM SHALL document `converged-stalled` and the thresholds. |  |
| AC-7 | test | WHEN `docs/agents/decisions/skillz-autoimprove.md` is read THE SYSTEM SHALL record the default-on stall stop and its thresholds as an ADR. |  |

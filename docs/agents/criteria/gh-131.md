# gh-131: the network preflight probes and the macOS live path

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-12 | test | WHEN a name lookup or a non-loopback connection succeeds, or its probe output is missing, THE SYSTEM SHALL raise `network-isolation-failed`, and `NETWORK_PROBE` SHALL differ from `loopback-tcp-http-v2`. |  |
| AC-13 | test | WHEN the Claude transport runs on macOS THE SYSTEM SHALL deny Bash reads of the host roots, the home directory, `/Volumes`, the per-user temp root, and the temporary directory, and SHALL allow the workspace; on Linux `denyRead` SHALL stay `["/"]`. |  |

# gh-694: validate reports each draft judged case that run refuses for its criteria

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/694

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN `validate --draft` reads a scored case of a `judge`, `hybrid`, or `journey` kind whose `expected.criteria` is missing or invalid THE SYSTEM SHALL report one `case-criteria-missing` or `case-criteria-invalid` finding with severity `error` for each such case, name the case id, and exit 1, as `run` refuses the same draft |  |
| AC-2 | test | WHEN `validate` reads the seed without `--draft`, or a draft whose judged cases all have valid criteria, THE SYSTEM SHALL report no criteria finding |  |

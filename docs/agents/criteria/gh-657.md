# gh-657: validate gates against pass and fail fixtures

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/657 (spec autoimprove-seed-signals C4)

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a gate has a `pass` fixture and the gate does not score 1 on it THE SYSTEM SHALL report the error `gate-unpassable` |  |
| AC-2 | test | WHEN a gate has a `fail` fixture and the gate scores above 0 on it THE SYSTEM SHALL report the error `gate-permissive` |  |
| AC-3 | test | WHEN a journey kind has `must` items and its gate scores a null trace above 0 THE SYSTEM SHALL report the warning `gate-null-trace` |  |
| AC-4 | test | WHEN a gate has no fixtures THE SYSTEM SHALL report the warning `gate-fixture-missing` and SHALL keep the case hash unchanged |  |
| AC-5 | test | WHEN `validate` runs a gate on a fixture THE SYSTEM SHALL run it as `python3 -I` in a temporary directory under a timeout, SHALL accept a Claude or Codex trace, and SHALL report `gate-fixture-timeout` when the timeout ends the gate |  |
| AC-6 | test | WHEN a gate fixture holds a symbolic link, a file that is not a regular file, or too many files, or its probe raises THE SYSTEM SHALL report the error `gate-fixture-unsafe` and SHALL NOT crash `validate` |  |

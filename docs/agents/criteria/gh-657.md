## Per-case proof verification notes

Per-case proof validation has four failure modes that the canonical gate alone does not expose:

- A draft selects commands, not the metadata-check boundary. Loaded seed metadata still requires checks, including when seed and draft identifiers overlap.
- Bounded grader JSON can raise `RecursionError` on Python 3.11 and 3.12. Decoder failures must remain execution errors, with later-case diagnostics preserved.
- `os.walk` can suppress unreadable-directory errors. Reject incomplete fixture traversal before execution, while retaining valid readable empty ordinary fixtures.
- Regex dot lookaheads can miss forbidden path components after newlines. Schema parity tests need invalid suffixes and valid newline-containing components.

These constraints preserve AC-20, AC-22, and AC-24 through AC-27. They introduce no new acceptance criterion or isolation promise.

# gh-339: the live smoke test fails on an unexpected preflight stop

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/339

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a scenario stops at the preflight stage AND the scenario does not expect that stop code, THE SYSTEM SHALL fail the test or report it as an error, not as PASSED. |  |
| AC-2 | test | WHEN the test reports a preflight stop, THE SYSTEM SHALL show the stage `preflight` and the stop code (for example `network-isolation-failed`) in the failure message. |  |
| AC-3 | test | WHEN a scenario stops at the preflight stage, THE SYSTEM SHALL keep `expect` in the record that `_run` returns. |  |
| AC-4 | test | WHEN a scenario expects a stop code AND the preflight stops with a different code, THE SYSTEM SHALL fail the test. |  |
| AC-5 | process | WHEN the README describes the pass rule, THE SYSTEM SHALL state that an unexpected preflight stop does not pass. | Review of `packages/skillz/tests/skillz_live/README.md` in the fix PR: the pass rule states that an unexpected preflight stop does not pass. |

# gh-512: the shared redactor redacts dotted, multiply escaped, and Unicode-quoted credential keys

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/512

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN raw text holds `password.md=\"one two zzcanary\" kept` THE SYSTEM SHALL return text without `zzcanary`. |  |
| AC-2 | test | WHEN raw text holds a quoted credential key at two or more escape layers THE SYSTEM SHALL return text without the value. |  |
| AC-3 | test | WHEN a credential key is followed by U+2019 and a value THE SYSTEM SHALL redact the value by the rule for an ASCII single quote. |  |
| AC-4 | test | WHEN `redact` receives a large input THE SYSTEM SHALL keep its cost linear in the input length. |  |

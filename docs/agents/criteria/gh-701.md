# gh-701: a run that does not score the task kind needs no family and no files on a task entry

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/701

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN `validate --kind journey` reads a journey-only target whose `evals.json` task entry has no `family`, with or without `files`, THE SYSTEM SHALL report neither `case-family-missing` nor `cases-invalid` |  |
| AC-2 | test | WHEN `run --kind journey` copies the seed of such a target to the draft unchanged THE SYSTEM SHALL stop with `cases-unapproved`, not `cases-invalid` |  |
| AC-3 | test | WHEN a run scores the `task` kind and a draft task case has no `family` THE SYSTEM SHALL stop with `cases-invalid` |  |
| AC-4 | test | WHEN `validate --kind` names a kind that the contract lacks THE SYSTEM SHALL report the contract finding and keep the task checks of a scored run, so a fileless task entry still gets `cases-invalid` |  |

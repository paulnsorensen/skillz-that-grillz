# gh-420: the journey gate resolves `--out` and `--target` against a `cd` in the same command

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/420

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a Bash command changes directory with `cd DIR` before the `skillz-experiment.pyz run` call THE SYSTEM SHALL resolve `--out` and `--target` against that directory before it judges the out-inside-target rule |  |
| AC-2 | test | WHEN a `cd` before the run call has no literal directory (bare `cd`, `cd -`, `cd ~...`, or `cd $VAR`) THE SYSTEM SHALL fail the out-inside-target rule |  |
| AC-3 | process | WHEN the branch is ready THE SYSTEM SHALL pass `just build` | pre-merge: `just build` exited 0 on the final commit |
| AC-4 | test | WHEN a directory change before the run call is not a plain `cd DIR` command (newline-separated, assignment prefix, `builtin cd`, `if`, brace group, `pushd`, `popd`, `env -C`, `env --chdir`) THE SYSTEM SHALL fail the out-inside-target rule |  |
| AC-5 | test | WHEN the agent snapshot holds a file under `output/toys/` that has no fixture under `toys/` THE SYSTEM SHALL fail the edited-target rule |  |

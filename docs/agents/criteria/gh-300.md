# gh-300: the train split gets at least 4 scored cases from 2 families

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/300

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN THE SYSTEM splits cases, THE SYSTEM SHALL give the train split at least 4 scored cases from at least 2 families, after the holdout minimum. |  |
| AC-2 | test | WHEN the suite is too small for both floors, THE SYSTEM SHALL stop with `cases-too-few` and name how many cases and families each split needs. |  |
| AC-3 | test | WHEN any assignment of whole families meets holdout 6, train 4 cases from 2 families, and validation 1 family, THE SYSTEM SHALL find one for every seed (checked by brute force over all suites of up to 6 families of 1 to 6 cases). |  |
| AC-4 | test | WHEN `validate --target skills/skillz` runs, THE SYSTEM SHALL exit 0 with `ok: true`, `split.holdout >= 6`, and `split.train >= 4` for the task kind. |  |
| AC-5 | test | WHEN the offline live smoke checks run, THE SYSTEM SHALL split every scenario suite without `cases-too-few`, and each scenario cap SHALL equal its measured estimate. |  |
| AC-6 | test | WHEN the approval question renders, THE SYSTEM SHALL show the train, validation, and holdout case and family totals. |  |

# gh-493: a run stops when its --out directory is inside the --target skill

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/493

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a run starts with `--out` inside `--target`, THE SYSTEM SHALL stop with the code `out-inside-target` and tell the user to use `mktemp -d` for a directory outside the skill. |  |
| AC-2 | test | WHEN a run resumes with `--out` inside `--target`, THE SYSTEM SHALL stop with the code `out-inside-target`. |  |
| AC-3 | test | WHEN `--out` is a sibling directory outside `--target` whose name starts with the target directory name, THE SYSTEM SHALL pass the guard. |  |
| AC-4 | test | WHEN the stop happens, THE SYSTEM SHALL make no model call, including no preflight call. |  |
| AC-5 | process | WHEN the experiments reference describes `--out`, THE SYSTEM SHALL name the `out-inside-target` stop. | Review of `skills/skillz/references/experiments.md` in the fix PR: the `--out` paragraph and the stop-code table name `out-inside-target`. |

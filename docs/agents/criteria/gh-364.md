# gh-364: a runner SIGKILL of the Gemini wrapper group does not orphan the sandbox child

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/364

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN the runner sends SIGKILL to the wrapper process group while `_run` waits for its sandbox child THE SYSTEM SHALL leave no child process running. |  |
| AC-2 | test | WHEN `_run` reaches its own timeout THE SYSTEM SHALL kill the child, call the stop callback, and leave the wrapper process running. |  |
| AC-3 | test | WHEN the wrapper starts a docker or podman sandbox container THE SYSTEM SHALL give the container a SIGKILL limit of at most `CONTAINER_GRACE` seconds after the runner SIGKILL (`SANDBOX_SECONDS` plus `TERM_GRACE_SECONDS`). |  |

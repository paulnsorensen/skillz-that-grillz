# gh-460: stop a live preflight call timeout with a resumable code

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/460

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a model call in the live preflight raises `CallTimeout` THE SYSTEM SHALL stop with the coded Stop `preflight-timeout`, raised from the `CallTimeout`. |  |
| AC-2 | test | WHEN the Stop `preflight-timeout` ends a run THE SYSTEM SHALL give it a `next` text that says a resume repeats the preflight, and SHALL write `failure_code` `preflight-timeout` to `run.json`. |  |
| AC-3 | test | WHEN a run stopped with `preflight-timeout` THE SYSTEM SHALL keep the phase `prepared` and record no `preflight`, and a resume in the same directory SHALL repeat the preflight and continue. |  |
| AC-4 | test | WHEN the live preflight raises a `RuntimeError` that is not a `CallTimeout` THE SYSTEM SHALL let it propagate unchanged. |  |
| AC-5 | process | The stop table in `skills/skillz/references/experiments.md` and ADR-013 name `preflight-timeout`. | review of the gh-460 pull request |

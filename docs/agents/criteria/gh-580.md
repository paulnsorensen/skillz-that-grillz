# gh-580: a fixture that many cases share counts once against the seed bound

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/580

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN many `evals/evals.json` entries list one fixture and the distinct fixture bytes stay under the seed bound THE SYSTEM SHALL write the seed with the fixture text once and stop with `cases-missing` |  |
| AC-2 | test | WHEN approved cases share one fixture THE SYSTEM SHALL write its text once to `RUN/cases.json` and load it into each case |  |
| AC-3 | test | WHEN a draft is a list of cases with inline `files`, or `RUN/cases.json` has no `fixtures` map, THE SYSTEM SHALL load the cases as before |  |
| AC-4 | test | WHEN the distinct fixture bytes pass the seed bound THE SYSTEM SHALL stop with `evals-unreadable` and stop reading fixtures |  |
| AC-5 | process | WHEN this change merges THE SYSTEM SHALL pass `just build` | `just build` exits 0 |

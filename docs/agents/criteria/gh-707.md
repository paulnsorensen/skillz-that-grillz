# gh-707: self-test takes each role model from the role file

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/707

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN `self-test --preflight-only --harness-config FILE` runs without `--model` and each role in FILE names its model THE SYSTEM SHALL run the preflight with each role's own model and exit 0 |  |
| AC-2 | test | WHEN `self-test --preflight-only` runs without `--model` and with no role file, or with a role file in which a role names no model, THE SYSTEM SHALL stop with the coded error `usage`, with no traceback, and name each such role and `--model` |  |

# gh-581: run wedge archives from the zip

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/581

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a wedge archive runs with `python -I` and read-only HOME, XDG_CACHE_HOME, and TMPDIR THE SYSTEM SHALL run its command without extraction. |  |
| AC-11 | test | WHEN wedge builds an archive THE SYSTEM SHALL not import or run shiv, and its package and archive SHALL not contain shiv. |  |
| AC-12 | test | WHEN wedge writes an archive THE SYSTEM SHALL deflate every file member. |  |
| AC-13 | test | WHEN `wedge check` reads a format-8 lock THE SYSTEM SHALL report stale, and `FORMAT_VERSION` SHALL be 9. |  |
| AC-8 | test | WHEN first-party code in an archive reads its own `.py` through `importlib.resources` THE SYSTEM SHALL return the source bytes, and `engine_hash`, `scoring_digest`, and `leakage_digest` SHALL return the same values from the archive as from the source checkout. |  |
| AC-9 | test | WHEN a harness preflight probe runs from an archive THE SYSTEM SHALL pass it a must-deny target for which `os.path.isfile` is true, so a probe that can read the target fails. |  |
| AC-19 | test | WHEN `skillz-experiment scaffold` runs from the archive THE SYSTEM SHALL read `_journey_gate.py` through `importlib.resources` and write the same draft contract as the source checkout. |  |
| AC-2 | test | Default builds SHALL include each pinned cache-tag tree and select the matching tree first. |  |
| AC-3 | test | An unknown interpreter tag SHALL use the full source closure. |  |
| AC-4 | test | A missing tree submodule SHALL load from source through PathFinder, and package resources SHALL remain readable. |  |
| AC-5 | test | Third-party bytecode SHALL match the modulefinder closure plus reached literal imports. |  |
| AC-6 | test | A third-party bytecode traceback SHALL include the source line. |  |
| AC-10 | test | Two independent cold builds SHALL be byte-identical; pins and subsets SHALL enter the content key. |  |
| AC-14 | test | Empty and subset bytecode settings SHALL select the exact trees; unsupported minors SHALL raise ConfigError. |  |
| AC-15 | test | Each skillz archive SHALL remain below 50 MB. |  |
| AC-18 | test | Every third-party module loaded by pinned-interpreter `--help` SHALL originate from matching-tree bytecode. |  |

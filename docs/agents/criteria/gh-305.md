# gh-305: Codex task temp files have no .git ancestor

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/305

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a Codex process starts THE SYSTEM SHALL set TMPDIR to a directory beside the workspace, create it, and leave it with no `.git` ancestor. |  |
| AC-2 | test | WHEN the Codex configuration is built THE SYSTEM SHALL grant write access only to the workspace, the task TMPDIR, and its `.git`, and drop the `:tmpdir` rule. |  |
| AC-3 | test | WHEN Codex runs a sandbox command THE SYSTEM SHALL pass the task TMPDIR in the environment and in the safe list, and create it. |  |
| AC-4 | test | WHEN the task TMPDIR is derived THE SYSTEM SHALL keep a socket path inside it under the AF_UNIX limit. |  |
| AC-5 | test | WHEN a workspace has no private parent directory THE SYSTEM SHALL refuse to derive a task TMPDIR with a ValueError. |  |
| AC-6 | process | WHEN the change lands THE SYSTEM SHALL pass `just build`. | `just build` exits 0 |

# gh-459: the planner admits a run that the search phase cannot start

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/459

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN the metric calls, less the overshoot margin and the validation outcomes, are below `MINIMUM_SEARCH_MARGIN` THE SYSTEM SHALL stop the plan with `budget-unapproved`, and the message SHALL name the validation size and say to lower --repeats or the holdout size, or change --seed or the case set. |  |
| AC-2 | test | WHEN the search allowance reaches `MINIMUM_SEARCH_MARGIN` THE SYSTEM SHALL admit the plan. |  |
| AC-3 | test | WHEN the plan admits a run THE SYSTEM SHALL leave a runtime search allowance (`search_ceiling` less the train and validation outcomes) of at least `MINIMUM_SEARCH_MARGIN`. |  |

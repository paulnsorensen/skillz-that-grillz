# gh-663: a partially failing regression case stays in its family mean

Source: gh-663 (GitHub issue; found by the `/age` review of PR #659)

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN the headroom pass records a regression case THE SYSTEM SHALL record `state`: `fail-to-pass` when the seed scores exactly 0 on every scored repeat, `pass-to-pass` when it scores exactly 1.0 on every scored repeat, and `partial` otherwise, and SHALL keep `reproduces` true only for `fail-to-pass` |  |
| AC-2 | test | WHEN the run selects the floor cases THE SYSTEM SHALL select only the `pass-to-pass` cases |  |
| AC-3 | test | WHEN a train family holds a regression case that the seed scores 0.5 and a plain case that it scores 0.95 THE SYSTEM SHALL keep both cases in the family mean and SHALL NOT stop with `cases-too-easy` |  |
| AC-4 | process | WHEN the docs change THE SYSTEM SHALL describe the three states and the floor rule | review of `experiments.md`, `eval-formats.md`, and ADR-018 |

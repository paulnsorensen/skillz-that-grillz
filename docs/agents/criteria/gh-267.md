# gh-267: acceptance-criterion traceability gate

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/267 (approved spec ac-traceability; the issue body is corrected by the spec)

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a test carries a bare `@pytest.mark.ac("AC-1")` in skillz, wedge, or fromargs THE SYSTEM SHALL fail pytest collection with a message that names the test and the expected `<source>:<id>` form |  |
| AC-2 | test | WHEN the migration is complete THE SYSTEM SHALL have every `ac` marker in the three packages in `<source>:<id>` form, with each source backed by a file in `docs/agents/criteria/`, and no id defined twice in one file |  |
| AC-3 | test | WHEN a criteria row has kind `test` and no test carries its `<source>:<id>` marker THE SYSTEM SHALL make `just build` fail and print that `<source>:<id>` |  |
| AC-4 | test | WHEN a marker names a source without a criteria file, or an id that its source file does not list THE SYSTEM SHALL make `just build` fail and print the marker's file and line |  |
| AC-5 | test | WHEN a criteria row has kind `process` and an empty `verified by` cell, or a kind other than `test` or `process` THE SYSTEM SHALL make `just build` fail and name the row |  |
| AC-6 | test | WHEN `check_ac_trace.py` runs THE SYSTEM SHALL read only files inside the repository and import no package under test |  |
| AC-7 | test | WHEN the fromargs mutation runner selects tests for a criterion THE SYSTEM SHALL select the same tests as before the migration |  |
| AC-8 | process | WHEN this change merges THE SYSTEM SHALL pass `just build`, with `docs/agents/criteria/gh-267.md` listing these criteria | `just build` exits 0 (the gate runs `ac-trace` and `ac-trace-tests`) |
| AC-9 | test | WHEN a marker argument is not a string literal or does not match `<source>:<id>`, a criteria file lists one id twice, or a criteria table is malformed THE SYSTEM SHALL make `just build` fail and print the file and line |  |
| AC-10 | test | WHEN a test gets its marker through a decorator, a module or class `pytestmark`, or `pytest.param(marks=...)` THE SYSTEM SHALL count it as a marked test for that criterion |  |

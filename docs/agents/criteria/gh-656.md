# gh-656: flag a seed that scores 0 through a setup fault, before the search

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/656 (spec `autoimprove-seed-signals`, C1)

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN the headroom pass finishes THE SYSTEM SHALL record `headroom.cases.<id>` with the split, the family, the score, the status, and the gate fault of every seed repeat, and a `mark` of `saturated` when every repeat scores exactly 1.0, `suspect-zero` when every repeat scores exactly 0, else null, and a resume SHALL keep a stored block that lacks these fields unchanged |  |
| AC-2 | test | WHEN every repeat of a case scores 0 and every repeat has a setup fault THE SYSTEM SHALL stop before the search with `cases-unscorable`, name each case and its diagnostic, and a resume SHALL refuse the same stop with no model call |  |
| AC-3 | test | WHEN every repeat of a case scores 0 and any repeat has no setup fault THE SYSTEM SHALL continue, print a `skillz-experiment: warning:` line, and store the warning in `headroom.warnings` |  |
| AC-4 | test | WHEN a regression case has the state `fail-to-pass` THE SYSTEM SHALL NOT mark it `suspect-zero` |  |

# gh-395: a macOS sandboxed command forges a sandbox setup failure through stderr

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/395

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a command that runs under `sandbox-exec` writes a standard error that starts with `sandbox-exec:` and exits non-zero THE SYSTEM SHALL return its exit code and standard error and SHALL NOT raise a sandbox setup failure |  |
| AC-2 | test | WHEN `sandbox-exec` itself prints `sandbox-exec:` on the process standard error and exits non-zero THE SYSTEM SHALL raise a sandbox setup failure |  |
| AC-3 | process | WHEN `just build` runs THE SYSTEM SHALL pass every gate | `just build` exits 0 |

# gh-235: freeze a run compatibility fingerprint (W2.4)

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/235

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a run reaches Session construction THE SYSTEM SHALL write `compatibility.fingerprint` and `compatibility.fields` to `run.json`, and the summary SHALL show the fingerprint. |  |
| AC-2 | test | WHEN two runs share every field THE SYSTEM SHALL give equal fingerprints, and `compare` SHALL return `()`. |  |
| AC-3 | test | WHEN two judged-contract runs differ only in the judge role's model THE SYSTEM SHALL return `("judge_model",)` from `compare`. |  |
| AC-4 | test | WHEN either record has no `compatibility` THE SYSTEM SHALL return `("missing-fingerprint",)` from `compare`. |  |
| AC-5 | test | WHEN the record is exported THE SYSTEM SHALL include the fingerprint and no case request or expected text. |  |
| AC-6 | test | WHEN the digest function runs over a copied package tree and a `gate/` file in the copy changes THE SYSTEM SHALL return a different `scoring_digest`. WHEN only a `search/` file changes THE SYSTEM SHALL return the same value. |  |
| AC-7 | process | WHEN `docs/agents/decisions/skillz-autoimprove.md` is read THE SYSTEM SHALL record the fingerprint fields and the scoring-digest rule as an ADR. | pre-gate: PR #256 review |

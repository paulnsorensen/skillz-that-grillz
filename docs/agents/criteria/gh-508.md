# gh-508: export a completed run from an earlier engine when its replay patch digest matches

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/508

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a completed run has an older `engine_hash` AND its recorded replay `patch_digest` equals the rebuilt patch digest, THE SYSTEM SHALL export it. |  |
| AC-2 | test | WHEN a completed run has an older `engine_hash` AND no recorded replay digest, or a different one, THE SYSTEM SHALL refuse the export with a coded error. |  |
| AC-3 | test | The gh-500 AC-8 test SHALL use a fixture with an older engine hash. |  |

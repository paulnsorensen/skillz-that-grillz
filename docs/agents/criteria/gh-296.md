# gh-296: the cases-missing stop writes the seed to a file and shows only counts

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/296

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN the skill has `evals/evals.json` and the run stops with `cases-missing` THE SYSTEM SHALL write the full seed case list to `RUN/cases.seed.json` with mode 0600 and name that path in the stop |  |
| AC-2 | test | WHEN the skill has `evals/evals.json` and the run stops with `cases-missing` THE SYSTEM SHALL keep fixture text and the seed case list out of the stop and show the case count and the count of each kind and each family |  |
| AC-3 | test | WHEN the skill has no `evals/evals.json`, or its `evals/evals.json` cannot seed the cases, THE SYSTEM SHALL name no seed file and remove an old `RUN/cases.seed.json` |  |
| AC-4 | process | WHEN this change merges THE SYSTEM SHALL pass `just build` | `just build` exits 0 |

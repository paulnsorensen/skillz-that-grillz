# gh-243: keep private cross-run attempt history for compatible runs (W4.6)

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/243

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN two compatible runs finish THE SYSTEM SHALL load the first run's attempts in the second run after a process restart, and the reflection prompt SHALL show a bounded summary without case text. |  |
| AC-2 | test | WHEN one compatibility field differs THE SYSTEM SHALL exclude the earlier run, name the field in the summary, and ignore its attempts for stagnation. |  |
| AC-3 | test | WHEN an earlier attempt was rejected THE SYSTEM SHALL show it in history, and it SHALL never become the winner. |  |
| AC-4 | test | WHEN a test seeds a distinctive holdout secret THE SYSTEM SHALL keep it out of the store and the prompt. |  |
| AC-5 | test | WHEN the store holds a corrupt line or cannot be read THE SYSTEM SHALL finish the run with the same result and report the skipped-line count or `history-unreadable`. |  |
| AC-6 | test | WHEN `run --no-history` runs THE SYSTEM SHALL neither read nor write the store, and a resume that changes the flag SHALL stop with `run-config-differs`. |  |
| AC-7 | test | WHEN `docs/agents/decisions/skillz-autoimprove.md` is read THE SYSTEM SHALL record the default-on history store, its location, its privacy rule, and `--no-history` as an ADR. |  |

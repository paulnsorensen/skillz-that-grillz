# gh-340: the live smoke resume scenario reports a stop before the interrupt

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a resume scenario stops before the interrupt step, THE SYSTEM SHALL NOT raise `KeyError`. |  |

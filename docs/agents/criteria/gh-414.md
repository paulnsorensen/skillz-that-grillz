# gh-414: inline links with a title or an angle-bracketed destination are local link targets

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/414

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a body holds an inline link with a title or a `<...>` destination THE SYSTEM SHALL report its target, without the angle brackets, in `local_link_targets`. |  |
| AC-2 | test | WHEN such a link escapes the package or crosses a symlink THE SYSTEM SHALL reject it as it rejects a plain link. |  |

# gh-403: links inside code fences and code spans are not local link targets

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/403

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a body holds an inline link inside a code fence or a code span THE SYSTEM SHALL leave it out of `local_link_targets` and SHALL NOT reject it as a package escape. |  |
| AC-2 | test | WHEN an inline link sits outside code THE SYSTEM SHALL still reject it when it escapes the package. |  |

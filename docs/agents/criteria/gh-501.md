# gh-501: give the proposer unmet criteria, edit hints, and gate output, and log each reflection (#320 Part 1)

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/501

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN the system builds feedback for a scored train case whose judge gave criterion `c1` level 3 and `c2` level 4, THE SYSTEM SHALL list `c1` as unmet with its text, `must` flag, level, and reason, AND SHALL NOT list `c2` |  |
| AC-2 | test | WHEN the request holds `output/plan.json` or a declared harness phrase, THE SYSTEM SHALL replace each occurrence with `[harness]` in the feedback `request` on the scored path AND on the rejected-candidate path |  |
| AC-3 | test | WHEN an unmet criterion text shares four normalized words with `SKILL.md` and with no other editable file, THE SYSTEM SHALL set `edit_hint` to `["SKILL.md"]`; WHEN it shares them with `SKILL.md` and `reference.md`, it SHALL set `edit_hint` to `["SKILL.md", "reference.md"]` sorted by name; WHEN no file matches, it SHALL set `edit_hint` to `["unknown"]`; in every case the candidate SHALL keep every editable file |  |
| AC-4 | test | WHEN a real command run through the evaluator scores below 1 with stderr that holds a secret pattern and is longer than 1,000 characters, for a `hybrid` gate and for a pure `command` grader, THE SYSTEM SHALL record `gate_diagnostic` on the outcome, AND the feedback from the fresh path and from the reuse path SHALL hold `gate_feedback` of at most 1,000 characters without the secret; WHEN capture fails with status `capture-failed`, `gate_feedback` SHALL hold the redacted `capture_failure` text |  |
| AC-5 | test | WHEN a case has 30 unmet criteria with 1,000-character texts, THE SYSTEM SHALL list all 30 ids with `must` and `level`, AND the text and reason fields SHALL total at most 4,000 characters, with `[truncated]` on each cut field |  |

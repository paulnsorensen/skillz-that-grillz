# gh-537: the proposer feedback carries task tokens when the run sets a token rule

Source: https://github.com/paulnsorensen/skillz-that-grillz/issues/537

| id | kind | criterion | verified by |
| --- | --- | --- | --- |
| AC-1 | test | WHEN a run sets a token rule (`min_token_saving` or `max_token_increase_per_gain`) AND an outcome has task usage, THE SYSTEM SHALL put the task token count and the incumbent mean for that case in the proposer feedback. |  |
| AC-2 | test | WHEN a run sets no token rule, THE SYSTEM SHALL leave the feedback record unchanged. |  |
